# 🚀 Shopify Engineer Portfolio

A modern, high-performance portfolio built using **React, Vite, Tailwind CSS, GSAP, and Framer Motion** to showcase real-world Shopify engineering projects, case studies, and system-level problem solving.

---

## 👨‍💻 About Me

I’m a **Senior Shopify Engineer** specializing in:

* Custom Shopify App Development
* B2B / Wholesale Architecture
* Performance Optimization (Core Web Vitals)
* ERP & Third-Party Integrations
* Conversion-Focused Storefront Development

This portfolio highlights **real production work**, not just UI projects.

* ⚡ Lightning-fast performance (Vite)

## 🚀 Getting Started

### 1. Clone the repository

```
git clone https://github.com/vinitgusai/portfolio.git
cd portfolio
```

### 2. Install dependencies

```
npm install
```

### 3. Run development server

```
npm run dev
```
